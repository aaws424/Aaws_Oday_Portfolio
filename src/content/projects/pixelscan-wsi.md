## Overview

PixelScan WSI builds whole-slide images from a live microscope feed: as the slide moves, frames are
stitched into a single large image in real time, with OpenCV and libvips doing the heavy image processing.
Beyond the engineering, the project covered the full release process for a commercial Windows
application, from packaging to Microsoft Store certification.
